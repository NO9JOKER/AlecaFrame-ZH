## 1. 目标

- 在不改变用户可见行为的前提下完成主链路架构重构；词典结构迁移与语义修正分阶段进行。
- 页面从“目录主结构”降级为 `pages.json` + 生成矩阵 + 适配器例外层。
- 词典成为一等公民：manifest、生成物隔离、人工词条按功能屏、override 有来源。
- launcher 模块化；OCR 搬到 `src/ocr/` 并建立边界，但逻辑不重写。
- 文档可生成、可校验；贡献者/复核 AI 有固定入口。

## 9. 残余风险

- launcher 拆分/OCR 搬家涉及真实安装与可选组件，真机证据可能无法覆盖所有机器。
- 词典语义修正（Cold/Range）会改变用户可见译文，需要显式 golden + 真机。
- 单人口径：没有外部用户，兼容性风险低，但“唯一用户=唯一测试者”意味着验证不能省。
- 文档/索引若未接入 CI 检查，仍可能漂移。
