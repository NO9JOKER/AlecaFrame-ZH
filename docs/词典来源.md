### 2.3 处理规则（`src/import_mioeu.py`）

1. 解析对象；丢弃空键/空值、含制表符/换行的条目、键无 ASCII 字母的条目、**译文不含中文**的条目、**英文 == 中文**的无意义条目（共 2 条）。
2. **基线只取「吸收 MIOEU 之前就存在的层」**：`items.tsv` + `vendor` + `fixes.tsv` + `extra-1..7.tsv`
   （`--baseline-extra-max` 可调）。`extra-8.tsv` 及之后是在 MIOEU 术语层存在之后按界面缺口补出的层，
   若把它们算进基线，本脚本的输出会随后续补缺文件变化、甚至循环依赖；因此默认排除。
   这样本脚本是**可重复运行**的：连续两次运行产出的 `mioeu-terms.tsv` 字节一致（已用 SHA-256 校验）。
3. 同名键：译文完全一致 → 计「已相同」丢弃；不一致 → 计「冲突」丢弃并写入差异报告（**我们的值优先**）。
4. 键仅大小写不同（如 `PrismaNaberus` vs `Prisma Naberus`）→ 计「大小写重复」丢弃。
5. 只有**我们完全没有的键**写入 `mioeu-terms.tsv`，按英文键排序，UTF-8 无 BOM、LF。

cd repo
