# 宿主与实现参考

> 本文记录 AlecaFrame/Overwolf 注入补丁的宿主事实与硬约束，供实现参考。
> 新架构以 [AGENTS.md](../AGENTS.md)、[ADR 0001](decisions/0001-capability-first-architecture.md)、[项目计划](project/v1.2.0-plan.md) 为准；本文不重复版本号、页面数量或词典条数。

## 1. 宿主与注入机制

- 目标：Overwolf 应用 AlecaFrame；补丁不修改官方签名/DLL。
- 启动器定位 `%LOCALAPPDATA%\Overwolf\Extensions\<appId>\<version>`，从官方 `app.opk`/已安装目录取官方页面。
- 启动方式：带 Overwolf 校验绕过参数启动；启动前先快照被改动的官方文件，`Restore` 能还原。
- 注入方式：把构建产物 `assets/js/alecaframe-zh-cn.js` 复制到扩展的 `web/assets/js/`，在每个目标页面 `</body>` 前插入 `<script>`；同一 bundle 注入多个页面。
- 页面清单以 `pages.json` 与生成的 `PAGE_MATRIX.md` 为准；不要在文档或代码里另写一份页面列表。

## 2. 页面与窗口语义

- 官方 manifest 定义多个窗口；哪些窗口被注入、哪些有专属适配器、哪些未覆盖，由 `pages.json` 选择并给出理由。
- `main` 是主窗口，承载多个功能屏（库存、铸造、市场、裂罅、源石、统计、仲裁、资源等）；不是单一功能页。
- `background` 是后台窗口，持有本地插件实例；插件级 hook 通常在这里安装。
- overlay/notification 窗口是独立小应用，通常只需要基础翻译；只有真正 DOM 特判才加适配器。
- OCR 是唯一可以按页面组织源码的子系统；页面脚本映射以 `src/ocr/manifest.json` 为准。

## 3. 启动器 Action（稳定行为）

| Action | 行为 |
|---|---|
| `Start` | 停 Overwolf → 还原官方文件 → 带 flag 启动 → 注入 bundle →（可选）OCR → 记录状态 |
| `Restore` | 停 Overwolf → 还原官方文件 → 正常启动 |
| `Toggle` | 带 flag 会话内切换注入/还原页面，并重载渲染进程 |
| `Refresh` | 中文会话内重新复制 bundle、重注入、重载渲染进程 |
| `Status` | 显示会话 flag、注入页数、OCR 状态、版本 |
| `OcrOn/OcrOff` | 读写设置并启停 OCR helper / 注入 OCR 脚本 |
| `InstallOcr` | 安装 OCR 便携依赖 |
| `InstallShortcuts` | 创建桌面快捷方式 |

## 4. 运行时

### engine

- 读取 `window.__AFCN_DICT__`，建立精确匹配索引与纯拉丁小写兜底索引。
- 翻译决策链：规范化 → 精确 → 大小写兜底 → 复合文本（节点/星球） → 规则；全部失败保持英文。
- DOM：TreeWalker 遍历文本节点/属性，MutationObserver 补翻；跳过 script/style/textarea/code/pre/noscript/option；超长文本不翻。
- 规则必须全串锚定、有防循环守卫；宽泛规则会误伤所有文本。

### search

- 基于整本词典建中文→英文反向索引，支持部件组合、Prime 后缀、子串兜底。
- 中文查询优先本地过滤；插件方法包装时清空 `search` 字段、强制全量，避免原生 100 条上限。
- 插件级 hook 在 background（本地插件实例），应用级 hook 在 main（Vue 实例）；两个窗口都注入同一 bundle。
- 宿主方法/对象不存在时只 `debugOnce` 并跳过，绝不抛异常；用 `__AFZH_SEARCH__` 诊断。

## 5. OCR（可选子系统）

- 本地 HTTP 服务 `127.0.0.1:38147`；页面脚本 + Node 服务 + Python/Paddle worker。
- 页面脚本部署名保持 `assets/js/afzh-*.js`；注入页面/顺序由 `src/ocr/manifest.json` 描述。
- 与 MIOEU 兼容的全局名、endpoint、端口、官方文件补丁点属于硬契约；逻辑变更另立项目。
- OCR 与主链路解耦：不装 OCR 也能汉化 + 中文搜索。

## 6. 硬契约

- 单 bundle、单 `<script>` 标签；所有页面共用。
- 全局名不改：`__AFCN__`、`__AFCN_DICT__`、`__AFCN_RELIC_REWARDS__`、`__AFCN_TRANSLATE__`、`__AFZH_SEARCH__`、`__AFZH_SEARCH_API__`、`__AFZH_SEARCH_TEST__`、`__ALECAFRAME_ZH_CN_ITEMS__`，以及 `src/ocr/CONTRACT.md` 中的 OCR 全局名。
- PowerShell 5.1 + UTF-8 BOM；快照/还原幂等；官方签名/DLL 不改。
- 运行时不得联网（OCR 仅 localhost）、不得读文件系统、不得写 secrets。
- 生成物不入库；`bin/` 只放生成物。

## 7. 常见坑

- Vue 重渲染会覆盖已翻译文本；需要 MutationObserver 再翻，闪烁是正常现象。
- `v-html`/图标会把句子拆成多个节点；逐节点翻译会导致整句无法匹配，需要整段处理或跳过。
- 规则太宽会误伤；数字/日期模板必须全串锚定并有防循环守卫。
- 插件与应用的 window 不同：hook 装错窗口会静默失效。
- 页面结构/选择器随宿主版本变化；升级后要核对 hook 方法与选择器。
- 交易历史依赖宿主在英文语言下解析/上传；中文下不可用属于宿主限制，不是 UI 门禁问题。
